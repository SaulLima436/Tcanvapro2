# Tcanvapro

- **App:** Tcanvapro, gestor de tareas mediante tablero Kanban.
- **Stack:** React + Vite en la interfaz; Node.js local para la API y SQLite para guardar tareas.
- **Inicio local:** `npm install`; en una terminal `npm run api` y en otra `npm run dev`; abre `http://localhost:5173`.
- **Convenciones:** interfaz y mensajes en español de Perú; importes, si se especifican, en soles (PEN). Mantener componentes y cambios pequeños. Implementar solo lo escrito en la spec; proponer antes cualquier función nueva. Pedir los datos imprescindibles y no incluir secretos en el código. Criterios de éxito comprobables desde la app.

Las reglas de producto viven en .specify/memory/constitution.md y el estado del producto en specs/README.md
