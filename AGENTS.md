# Tcanvapro

- **App:** Tcanvapro, gestor de tareas mediante el tablero canva.
- **Stack vigente:** React + Vite para la aplicación web; SQLite como base de datos. Mantener
  la solución simple y no añadir tecnologías ni dependencias sin necesidad especificada.
- **Local:** con Node.js y npm instalados, ejecutar `npm install` y `npm run dev`; abrir la URL
  local que indique Vite. Ejecutar `npm test` para las pruebas cuando estén configuradas.
- **Convenciones:** código y experiencia en español de Perú; importes en soles (PEN). Usar
  componentes y cambios pequeños y legibles. No implementar funcionalidades fuera de la spec;
  proponer primero cualquier idea nueva. Solicitar solo datos imprescindibles y no guardar
  secretos en el código. Los criterios de éxito deben comprobarse desde la app sin leer código.

Las reglas de producto viven en .specify/memory/constitution.md y el estado del producto en specs/README.md
